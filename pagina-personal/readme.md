Página Personal - Alondra Iridany Saucedo Jiménez

¡Bienvenido/a a mi repositorio! Esta es una página web de presentación personal minimalista y estilizada, diseñada con un tema floral elegante para dar a conocer mi perfil profesional como estudiante de desarrollo de software.

🌸 Acerca del Proyecto

El objetivo de este proyecto es servir como una tarjeta de presentación web digital moderna, responsiva y estéticamente cuidada, destacando tipografías elegantes y animaciones decorativas suaves.

🛠️ Tecnologías Utilizadas

HTML5: Estructura semántica del documento web.

CSS3: Estilos visuales, diseño adaptativo (responsive) y animaciones decorativas (pétalos).

Google Fonts:

Great Vibes (Estilo caligráfico/cursivo)

Quicksand (Tipografía moderna sans-serif)

📂 Estructura del Proyecto

pagina-personal/
├── index.html     # Estructura principal de la página web
├── styles.css     # Estilos, animaciones y diseño responsivo
└── README.md      # Documentación del proyecto


🚀 Cómo Visualizar el Proyecto Localmente

Clona el repositorio:

git clone https://github.com/cristianavendano-code/P-gina-personal.git


Navega al directorio del proyecto:

cd P-gina-personal


Abre el archivo index.html:

Haz doble clic sobre el archivo index.html en tu navegador de preferencia.

O utilízalo mediante la extensión Live Server en Visual Studio Code.
